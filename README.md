# IrisScanner — сканирование радужки глаза

Программа предназначена для простого сканирования области глаза с помощью веб-камеры.

Программа **не распознаёт человека**, **не сравнивает глаз с базой данных** и **не сохраняет биометрические данные**. Она только обнаруживает лицо, ищет глаза и пытается определить окружность радужки на изображении.

## Назначение программы

Принцип работы:

```text
Веб-камера
    ↓
Обнаружение лица
    ↓
Поиск глаз
    ↓
Выделение внутренней области глаза
    ↓
Поиск окружности радужки
    ↓
Отображение области радужки
    ↓
Визуальный результат на экране
```

Программа предназначена именно как модуль сканирования для будущей системы СКУД.

---

# Что делает программа

При запуске программа:

1. Проверяет наличие моделей распознавания лица и глаз.
2. При отсутствии моделей автоматически скачивает их.
3. Открывает веб-камеру.
4. Находит лицо.
5. Выбирает самое большое найденное лицо.
6. Находит глаза в верхней части лица.
7. Для найденного глаза выделяет внутреннюю область.
8. Применяет размытие для подготовки изображения.
9. Использует Hough Circle Transform для поиска круглой области радужки.
10. Отображает результат на изображении с камеры.
11. Создаёт увеличенное цветное изображение области радужки.
12. Показывает условный прогресс сканирования.

Выход из программы:

```text
ESC
```

# Используемые модели

Программа использует две XML-модели Haar Cascade.

## Модель лица

Файл:

```text
haarcascade_frontalface_default.xml
```

Источник:

```text
https://raw.githubusercontent.com/opencv/opencv/4.x/data/haarcascades/haarcascade_frontalface_default.xml
```

Используется для обнаружения лица.

## Модель глаз

Файл:

```text
haarcascade_eye.xml
```

Источник:

```text
https://raw.githubusercontent.com/opencv/opencv/4.x/data/haarcascades/haarcascade_eye.xml
```

Используется для поиска глаз внутри области лица.

# Камера

По умолчанию используется первая камера:

```csharp
new VideoCapture(
    0,
    VideoCaptureAPIs.DSHOW);
```

Значение:

```text
0
```

означает первую доступную камеру.

Если камер несколько, можно попробовать:

```csharp
new VideoCapture(
    1,
    VideoCaptureAPIs.DSHOW);
```

или:

```csharp
new VideoCapture(
    2,
    VideoCaptureAPIs.DSHOW);
```

---

# Разрешение камеры

Программа запрашивает разрешение:

```text
1280 × 720
```

Настройки находятся здесь:

```csharp
camera.Set(
    VideoCaptureProperties.FrameWidth,
    1280);

camera.Set(
    VideoCaptureProperties.FrameHeight,
    720);
```

Фактическое разрешение зависит от возможностей камеры.

---

# Обнаружение лица

Для поиска лица используется:

```csharp
CascadeClassifier
```

с моделью:

```text
haarcascade_frontalface_default.xml
```

Поиск выполняется на чёрно-белом изображении.

Перед поиском программа преобразует кадр:

```text
BGR → GRAY
```

и применяет:

```csharp
Cv2.EqualizeHist(
    gray,
    gray);
```

Это используется для выравнивания контраста изображения.

---

# Выбор лица

Если в кадре найдено несколько лиц, программа выбирает самое большое:

```csharp
Rect face =
    faces
        .OrderByDescending(
            f => f.Width * f.Height)
        .First();
```

Таким образом основным объектом сканирования становится ближайшее или визуально наиболее крупное лицо.

---

# Область глаз

После обнаружения лица программа берёт верхнюю часть области лица.

Используется:

```csharp
face.Height * 0.60
```

Эта область передаётся в детектор глаз.

---

# Поиск глаз

Для обнаружения глаз используется:

```text
haarcascade_eye.xml
```

Поиск выполняется методом:

```csharp
DetectMultiScale()
```

Для найденного глаза создаётся отдельная область обработки.

На изображении эта область обозначается жёлтой рамкой.

---

# Поиск радужки

После нахождения глаза программа выделяет его внутреннюю часть.

Затем применяется:

```csharp
Cv2.GaussianBlur()
```

с параметрами:

```text
7 × 7
sigma = 1.5
```

После подготовки изображения используется:

```csharp
Cv2.HoughCircles()
```

Метод ищет окружность, которая может соответствовать радужке.

Используются ограничения:

```text
minRadius = высота области / 6
maxRadius = высота области / 2
```

Из найденных окружностей выбирается окружность с наибольшим радиусом.

---

# Отображение радужки

При обнаружении радужки программа рисует:

### Красный круг

Показывает предполагаемую границу радужки.

### Голубой внутренний круг

Показывает дополнительную внутреннюю область.

### Белую точку

Показывает центр найденной окружности.

### Радиальную сетку

Вокруг центра проводится 12 направлений:

```text
12 сегментов
```

Они образуют условную сетку сканирования.

### Вращающийся луч

Красный луч постоянно меняет угол.

Это является **только визуальной анимацией сканирования** и не означает проведение реального оптического сканирования.

---

# Увеличение радужки

При обнаружении радужки программа вырезает область вокруг найденного центра из исходного цветного изображения.

Размер области зависит от:

```csharp
int zoom = 6;
```

Чем больше значение `zoom`, тем большую область исходного изображения используется вокруг радужки.

Размер окна увеличенной области:

```csharp
const int zoomDisplaySize = 500;
```

То есть область выводится примерно как:

```text
500 × 500
```

---

# Важная особенность увеличения

Увеличение выполняется непосредственно из:

```csharp
frame
```

а не из:

```csharp
gray
```

Поэтому окно увеличенной радужки остаётся **цветным**.

# Прогресс сканирования

Программа использует переменную:

```csharp
double scanProgress = 0;
```

При обнаружении радужки:

```text
+1.5
```

При отсутствии радужки:

```text
-1.0
```

Максимальное значение:

```text

```

Минимальное значение:

```text
0%
```

Важно: этот процент является **визуальным индикатором обнаружения**, а не показателем качества или завершения настоящего биометрического сканирования.

# Если радужка не находится

На экране будет:

```text
LOOK AT CAMERA
```

Попробуй:

- смотреть прямо в камеру;
- приблизить лицо;
- использовать хорошее освещение;
- не закрывать глаза;
- убрать сильные блики;
- убедиться, что глаз достаточно хорошо виден камере.

Обычная веб-камера может плохо определять радужку, особенно на большом расстоянии или при низком разрешении.

---

# Если лицо не находится

Программа не сможет перейти к поиску глаз.

Проверь:

- лицо находится перед камерой;
- освещение достаточное;
- лицо не слишком маленькое;
- камера работает;
- приложение использует правильную камеру.

---

# Если камера не открывается

В консоли появится:

```text
Не удалось открыть камеру.
```

Проверь:

1. Камера не занята другим приложением.
2. Windows разрешает доступ к камере.
3. Правильно указан индекс камеры.

По умолчанию:

```csharp
VideoCapture(0, VideoCaptureAPIs.DSHOW)
```

# Что программа НЕ делает

Текущая версия является исключительно модулем визуального сканирования.

Она не делает:

```text
❌ распознавание личности
❌ сравнение с базой
❌ поиск пользователя
❌ регистрацию пользователя
❌ выдачу доступа
❌ открытие замка
❌ управление турникетом
❌ запись биометрического шаблона
❌ сохранение фотографии глаза
❌ идентификацию человека по радужке
```

Сейчас логика максимально простая:

```text
КАМЕРА → ГЛАЗ → РАДУЖКА → ЭКРАН
```

---

# Ограничение метода

Эта программа **не является настоящим сканером радужки или сетчатки глаза**.

Она использует обычное изображение с веб-камеры и компьютерное зрение для поиска области, имеющей форму окружности.

Настоящее специализированное устройство для биометрического сканирования глаза требует специализированной оптики и/или сенсора.

Поэтому результат:

```text
IRIS DETECTED
```

означает, что алгоритм обнаружил подходящую круглую область изображения, а не то, что личность пользователя установлена.
